# cebu

엄마의 세부 여행 안내 페이지 (2026년 10월 29일 ~ 11월 2일).

휴대폰에서 보기 좋게 만든 한 페이지짜리 사이트예요. 아래 메뉴로 일정, 그랩, 돈, 숙소, 주의할 것, e유심 안내를 볼 수 있어요.

## 폴더 구성

```
index.html      페이지 내용
css/style.css   디자인 (글자 크기, 색, 배치)
js/script.js    동작 (탭 이동, 날짜 고르기, 쇼핑 체크, 편지, 호텔 이름 복사, 가이드 전화)
file/           사진 (화면 캡처, 지폐·동전, 음식·기념품 item-*, 장소 place-*)
```

네 가지가 같이 있어야 페이지가 제대로 보여요.
